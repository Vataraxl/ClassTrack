课轨 ClassTrack 是纯本地运行的高校课表应用，将每一堂课谱写成黑胶唱片里的专属音轨。

跨节音轨与弹性作息

自动合并 3 节及以上的实验课与专业长课，精准解析单双周与离散周次；支持 6–16 节每日课表与作息顺延。

物理实验综合长课 3 节连堂 · 2,6,8-18周

内置教务网页一键导课

通过应用内 WebView 登录本校教务直接提取二维课表，兼容跨行合并与同格多课，已预置 17 个高校入口及五大主流教务系统。

零重绘开销的液态玻璃

在「经典纯净」与「液态玻璃」双材质间无缝切换。基于 Compose drawWithCache 缓存全部画笔，滑动与翻周保持满帧丝滑。
